LPU FreshStart
A Digital Student Onboarding and Orientation Platform
LPU FreshStart is a responsive academic web application designed to help newly admitted students at Lovely Professional University navigate their first fifteen days on campus.

Live Website | GitHub Repository
Problem Statement
P03 – First Fifteen Days: New-Student Onboarding and Orientation at LPU

New students may face difficulties finding classrooms, navigating campus, understanding university systems and accessing essential services. LPU FreshStart brings onboarding guidance into one centralized platform.
Objectives
- Simplify student onboarding and campus navigation.
- Provide accessible information about university services.
- Help students organize their first fifteen days.
- Support domestic and international students.
- Reduce confusion through a user-friendly digital interface.
Features
The dashboard provides centralized navigation, global search and onboarding progress tracking.

Design Thinking Approach
1. Empathize: Understand new students' onboarding challenges.
2. Define: Identify navigation, orientation and information-access problems.
3. Ideate: Propose a centralized student assistance platform.
4. Prototype: Develop a responsive and interactive web application.
5. Test: Evaluate functionality, navigation, usability and data persistence.

How to Use
1. Open the live website.
2. Explore the dashboard and navigation menu.
3. Create a student profile using demonstration data.
4. Explore campus facilities and student assistance sections.
5. Track onboarding tasks and organize personal events.
Testing
Individual features have undergone developer-side manual checks, including navigation, search, filters, forms, favourites and local storage. A comprehensive independent audit has not been performed.
Privacy and Limitations
- This is a frontend academic prototype, not an official LPU application.
- Saved information is stored locally in the browser; there is no backend or cross-device synchronization.
- Classroom records and orientation schedules include demonstration data.
- Campus map positions are approximate; live GPS navigation is not supported.
- Translation is limited to predefined phrases.
- Saved reminders do not send background notifications.
- Current campus policies, locations, menus, prices and service availability require official verification.
- No banking credentials or financial documents are collected.
Future Scope
- Verified university information and campus data.
- Secure authentication and backend integration.
- Real-time navigation and university announcements.
- Expanded multilingual assistance and notification support.
